## Berkas Perancangan Project
Folder ini memuat dokumen spesifikasi resmi kebutuhan sistem dan produk untuk project SPLW Mobile:

1. **`BRD_SPLW_MOBILE.pdf` (Business Requirement Document)**
   - Menjelaskan latar belakang bisnis, justifikasi migrasi dari versi web (Laravel 12) ke mobile (Flutter + FastAPI), analisis stakeholder, diagram Use Case, aturan bisnis (BR-01 s/d BR-14), dan persyaratan fungsional/non-fungsional.
2. **`PRD_SPLW_MOBILE.pdf` (Product Requirement Document)**
   - Menjelaskan spesifikasi detail produk: user personas, user stories prioritas MoSCoW, product backlog (PB-01 s/d PB-18), roadmap iterasi (Iterasi 1–4), sitemap navigasi (S-01 s/d S-15), kontrak API FastAPI JSON, rancangan wireframe/mockup, acceptance criteria, dan rencana pengujian.
