## Ringkasan Laporan
- **BAB I: Pendahuluan & Tujuan**: Memahami LBS, Location Manager, Location Provider, serta integrasi peta dan koordinat GPS.
- **BAB II: Dasar Teori**: Arsitektur LBS, GPS Satelit vs Cellular BTS, Google Maps Platform API Key, Rumus Haversine untuk kalkulasi jarak, dan izin runtime Android.
- **BAB III: Pelaksanaan Praktikum**: Implementasi Location Provider untuk membaca koordinat GPS perangkat, status ketersediaan sinyal, dan proyeksi titik pada peta.
- **BAB IV: Pembahasan Tugas**: Aplikasi PetaWisata Indonesia dengan 15 destinasi wisata, filter 5 kategori, pencarian reaktif, pengurutan jarak LBS terdekat, dan navigasi rute Google Maps.
- **BAB V: Kesimpulan & Refleksi**: Analisis integrasi LBS pada Flutter, penanganan izin lokasi, dan pemetaan konsep modul native ke Flutter modern.
